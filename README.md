# ModernSpace

Personal dimensions for Forge 1.20.1: a port of GTNH [PersonalSpace](https://github.com/GTNewHorizons/PersonalSpace)
(LGPL-3.0), moved out of GregTech Nexus Addon into a standalone mod.

- Mod id: `modernspace` (stored in saves; do not change).
- Required: [Infiniverse](https://www.curseforge.com/minecraft/mc-mods/infiniverse) 1.0.0.5+.
- Portal block opens the world editor (layers, biome, sky, weather, streets); `/pspace` commands as the original.
- Config: `config/modernspace/personal_space`.
- Recipe: shaped obsidian / eyes of ender / diamond block; modpacks can replace it.

Build: `./gradlew build` (JDK 17+). License: LGPL-3.0-or-later (see LICENSE and COPYING).
